# ANVESHAN — Roadmap

- **v1.0 (Current Build):** Core FastAPI + SQLite platform, SymPy/NumPy/SciPy Math & Physics engines, OpenAlex/arXiv/PubChem literature clients, Falsifiable Hypothesis Verification engine, immutable experiment ledger with reruns, replaceable Gemini API adapter, responsive tablet-friendly Research Lab UI, full automated test suite, Docker/Render/CI configs.
- **v1.1 (Post-Push Live Verification):** Push `feat/anveshan-v1-core` to GitHub, run GitHub Actions CI, verify live OpenAlex/arXiv/PubChem & Gemini API calls on a networked host (Termux or Render), and open PR into `main`.
- **v1.2 (Extended Scientific Modules):** Unit-checked dimensional analysis (`pint`), CSV/JSON dataset upload & statistical hypothesis testing workbench, BibTeX/RIS export, and multi-user authentication (JWT/OAuth) if deployed publicly.
