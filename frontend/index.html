Explore Live Demos 8 REAL WORKFLOWS

1. Mathematical Engine

Safe SymPy symbolic calculus & algebra, NumPy/SciPy statistical testing, OLS regression, and seeded Monte Carlo π estimation.

Solves: Verifiable analytical derivations and statistical inference with correlation-vs-causation warnings.
Limits: 300-char expression limit; univariate OLS.

2. Physics Simulation Engine

Five deterministic SciPy RK45 ODE models (Oscillator, Projectile w/ Air Drag, Radioactive Decay, Thermal Cooling, Logistic Growth) verified against analytical solutions.

Solves: Quantitative comparison of numerical solvers against exact closed-form physics.
Limits: Classical deterministic ODEs; units tracked via metadata.

3. Hypothesis Verification

Define explicit assumptions, falsifiable predictions, and numeric acceptance criteria; execute real computational tests.

Solves: Transparent falsification preserving both supported and failed runs.
Limits: Computational support is not universal physical proof.

4. CSV Data Analysis

Upload a CSV file (or load clearly labeled sample data) for Pandas descriptive stats, missing-value counts, Pearson correlation, and OLS regression.

Solves: Rapid reproducible tabular auditing with SHA-256 dataset checksums.
Limits: 2 MB file cap; correlation does not imply causation.

5. Experiment Ledger

Append-only SQLite ledger with immutability triggers, SHA-256 parameter checksums, and deterministic reruns.

Solves: Auditability and exact computational reproducibility across runs.
Limits: SQLite triggers prevent SQL mutation, not OS-level file edits.

6. Scientific Literature

Real HTTP clients for OpenAlex, arXiv (Atom XML), and PubChem PUG-REST with respectful rate-limit guards.

Solves: Verifiable metadata & source URL tracking without fabricated citations.
Limits: Requires outbound internet; displays NOT_CONNECTED if offline.

7. Evidence Export

Download genuine Markdown Experiment Evidence Reports and BibTeX citation files directly from persisted SQLite records.

Solves: Reproducible sharing of parameters, checksums, and literature references.
Limits: Exports only real persisted records.

8. AI Synthesis (Optional)

Replaceable Google Gemini REST adapter via server-side GEMINI_API_KEY environment variable.

Solves: Hypothesis ideation while keeping core math & physics 100% key-free.
Limits: Displays NOT_CONFIGURED when key is unset; never fakes AI output.

CSV Data Analysis Workbench PANDAS + SCIPY + SHA-256

Platform Documentation & API Reference

Verified REST API Endpoints

GET  /api/system/status              - Live SQLite counts, runtime versions, AI status
POST /api/math/symbolic              - SymPy symbolic simplify/diff/integrate/solve/expand/factor
POST /api/math/statistics            - NumPy/SciPy stats, Shapiro-Wilk, t-test, OLS regression
POST /api/math/monte-carlo-pi        - Seeded deterministic Monte Carlo Pi estimation
POST /api/physics/oscillator         - Damped Harmonic Oscillator (RK45 vs analytical)
POST /api/physics/projectile         - 2D Projectile Motion with Quadratic Air Drag
POST /api/physics/decay              - First-Order Radioactive Decay
POST /api/physics/cooling            - Newton's Law of Thermal Cooling
POST /api/physics/logistic           - Logistic Population Growth
POST /api/datasets/analyze           - Pandas CSV stats, SHA-256, Pearson corr, OLS
POST /api/hypotheses                 - Create falsifiable hypothesis with acceptance criteria
POST /api/hypotheses/{id}/verify     - Execute real computational verification test
GET  /api/experiments                - List immutable SQLite experiment ledger
POST /api/experiments/{id}/rerun     - Re-execute and verify deterministic reproducibility
GET  /api/experiments/{id}/report    - Download Markdown Experiment Evidence Report
POST /api/literature/search          - OpenAlex, arXiv, PubChem live search
GET  /api/literature/export/bibtex   - Download BibTeX citations from saved sources
POST /api/ai/analyze                 - Optional Gemini API synthesis (key-protected)
